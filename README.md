## About

Security analyst with 7+ years across vulnerability assessment and penetration testing for web, mobile, API, and network targets. I own engagements end to end — scoping, testing, manual verification of every automated finding, client walkthroughs, remediation guidance, and retesting.

On the defensive side, I work in Azure Sentinel and Azure Identity and Access Management: Conditional Access, RBAC, MFA, and identity protection across hybrid infrastructure. I'm currently completing an M.Sc. in Engineering and Technology for Strategy and Security at the University of Genoa, where the focus is the intersection of offensive security, detection engineering, and applied machine learning.

- 🔭 Currently building a machine-learning intrusion detection pipeline and an Azure Sentinel detection lab (see **Featured projects** below)
- 🌱 Working toward OSCP and Microsoft SC-200
- 💬 Ask me about OWASP Top 10 testing, Burp Suite workflows, or Azure IAM hardening
- 📫 vidya13.g@gmail.com
- ⚡ Available full-time from February 2027 — open to internship and working-student opportunities before then
